# Мануал: сопоставление запчастей с группами

Программа предлагает для каждого названия запчасти группу из вашего списка (`groups.txt`). Вы проверяете и исправляете, а исправления запоминаются. Чем больше проверенных данных в памяти, тем точнее подсказки.

---

## 1. Что нужно для работы

| Файл | Назначение |
|---|---|
| `fill_groups_gui.py` | Точка входа. Запуск: `python fill_groups_gui.py` (или готовый exe) |
| `app.py` | Главное окно |
| `matcher.py` | Алгоритм сопоставления |
| `matcher_data.py` | Данные алгоритма: сокращения и синонимы (`ABBREV`), модификаторы, окончания и т. п. Лежит рядом с `matcher.py` |
| `app_config.py` | Чтение и запись настроек |
| `settings_window.py` | Окно «Настройки» |
| `app_settings.json` | Настройки: названия столбцов, обобщённые группы, правила, автосохранение |
| `groups.txt` | Список групп, по одной в строке |
| `matching_memory.json` | Память: подтверждённые пары «название → группа» |

Создаются сами:
- `matching_memory.json.bak` — предыдущая версия памяти;
- `*.corrupt-…` — копия повреждённого файла памяти;
- папка `remzona_groups_logs` — автосохранения (до 10 файлов каждого вида).

Обучаемой модели и отдельных скриптов переобучения в программе нет. Вся «память» — это `matching_memory.json`, она пополняется сама во время работы. Старые файлы `rows_matcher.json`, `matcher_model.json` и скрипты `train_model.py`, `audit_memory.py`, `check_data.py` программа не использует, их можно удалить.

Файл `check_matcher_loo.py` необязателен. Он оценивает точность на вашей истории: каждая запись по очереди убирается из памяти, и проверяется, угадает ли её алгоритм. Запускать из папки приложения. Цифра обычно ниже, чем на обычном файле, потому что в истории в основном трудные случаи (то, что вы исправляли).

---

## 2. Как программа принимает решение

Для каждого названия по порядку:

1. **Память.** Название очищается, и если такая фраза уже подтверждена, берётся её группа (уверенность 100%).
2. **Правила** (Настройки → «Правила»), сверху вниз, побеждает первое подходящее (100%).
3. **Подбор по смыслу.** Для каждой группы считается оценка из нескольких частей:
   - совпадение слов названия с названием группы (редкие слова весят больше частых);
   - сходство с примерами из памяти (похожие названия, которые вы уже распределили);
   - главное слово названия («вал», «сальник», «накладка»);
   - бонус, если название совпадает с названием группы или содержит его целиком;
   - штрафы за слова группы, которых нет в названии, и за противоречия (левый/правый, перед/зад и т. п.);
   - синонимы и сокращения: «ремень ГРМ», «стойка стаб.», «облицовка порога» приводятся к названиям, которыми пользуетесь вы.

Важные следствия:
- **Память сильнее правил.** Если в памяти лежит ошибочная запись для точной фразы, правило её не переопределит. Исправляйте саму запись, назначив верную группу заново.
- 100% выдаётся только для памяти и правил. Для остальных строк уверенность — это оценка надёжности подсказки.
- Модификаторы (левый, правый, цвет, размер) сами в память «по словам» не учатся: они не должны перетягивать группу.

### Как читать уверенность

Это ориентир, а не гарантия. Проверка на вашей памяти (5365 записей, `check_matcher_loo.py`, самый трудный режим) показала:

| Уверенность | Верных в проверке | Что делать |
|---|---|---|
| ≥ 0,97 | 93% | Просматривать глазами, особенно однословные названия и пары вроде «Обшивка багажника / Обшивка стойки» |
| 0,90–0,97 | 63% | Проверять каждую |
| 0,75–0,90 | 53% | Проверять каждую |
| 0,55–0,75 | 35% | Решать самостоятельно, подсказка слабая |
| < 0,55 | 21% | Решать самостоятельно (фильтр «Низкая уверенность») |

На обычных файлах точность выше, чем в этой проверке: в истории в основном трудные случаи, которые вы исправляли.

Если у двух групп почти равные оценки, уверенность занижается. Такая строка попадёт в «Низкую уверенность».

## 3. Работа в программе

### Основной цикл
1. **Обзор…** — выбрать Excel с запчастями. Названия столбцов задаются в Настройках (по умолчанию «Имя артикула», «Название группы», «Имя бренда», «Артикул на сайте»).
2. **1. Загрузить и сопоставить** — программа предлагает группу для каждой строки и подставляет её в «Итоговая группа».
3. Проверка таблицы (см. ниже).
4. **2. Сохранить результат** — Excel с проставленными группами.
5. **3. Сохранить лог сопоставления** — подробный лог для анализа и обучения.

**Важно:** предложенные группы подставляются в таблицу сразу, но **в память попадает только то, что вы назначили вручную** (двойной клик, выбор из альтернатив, протягивание и т. д.). Непроверенные предложения не запоминаются.

### Таблица
Столбцы: №, Название запчасти, Предложение, Альтернативы, Итоговая группа, Google, Remzona.

- Столбцы всегда помещаются в окно. Если вы тянете границу столбца, остальные сжимаются, а не уезжают за экран. Окно можно менять в размере, столбцы перераспределяются пропорционально. Самые широкие — «Название», «Предложение» и «Альтернативы».
- **Двойной клик по «Альтернативы»** — кнопки с топ-3 группами (с процентами) и кнопка «Другой вариант…» для поиска по всем группам. **Esc** закрывает окно.
- В самой ячейке «Альтернативы» названия сокращены (около половины длины), чтобы были видны оба варианта. Полный текст виден во всплывающей подсказке при наведении.
- **Двойной клик по «Итоговая группа»** — поиск по всем группам: вводите часть названия, стрелка вниз и Enter. **Esc** закрывает окно.
- **Клик по «Google»** — поиск по бренду и артикулу. **Клик по «Remzona»** — поиск названия на Remzona.
- Подсказка с полным текстом ячейки появляется, если навести курсор и подождать.

### Фильтры
«Показать все», «Только с предложением», «Только без группы», «Низкая уверенность» (уверенность < 0,55).

### Несколько строк
- Ctrl+клик и Shift+клик — выделить несколько. Ctrl+A — выделить все видимые.
- **Ctrl+D** — протянуть группу из верхней выделенной строки на остальные.
- **ПКМ → «Назначить группу выделенным строкам…»** — один выбор для всех.
- **ПКМ → «Назначить эту группу всем строкам с таким же названием»** — проставляет группу всем строкам таблицы с тем же очищенным названием, даже скрытым фильтром.
- **ПКМ → «Создать правило из строки…»** — правило «фраза → группа» из выделенной строки (фразу можно укоротить).
- **ПКМ → «Очистить группу»**, копирование ячейки и строки.

### Горячие клавиши (работают в EN и RU раскладках)

| Клавиши | Действие |
|---|---|
| Ctrl+C | Копировать ячейку (из столбца последнего клика) |
| Ctrl+V / Ctrl+X | Вставить / вырезать в полях ввода |
| Ctrl+A | Выделить всё: в поле ввода весь текст, в таблице все строки |
| Ctrl+D | Протянуть группу вниз |
| Ctrl+Z | Отменить последнее назначение |
| Ctrl+Backspace / Ctrl+Delete | Удалить слово целиком назад / вперёд в полях ввода |
| Esc | Закрыть окно выбора группы |

**Ограничение отмены:** Ctrl+Z возвращает значение в таблице, но **не откатывает память**. Если назначили не ту группу, назначьте правильную заново: запись для этой фразы перезапишется.

### Настройки
- **Столбцы и файл групп** — названия столбцов Excel, путь к `groups.txt`.
- **Обобщённые группы** — группы вроде «Болты, винты», «Гайки, шайбы». Они побеждают реже, чем конкретные. «Порог отрыва» (по умолчанию 1,5): чем он больше, тем реже побеждают обобщённые.
- **Правила** — добавить, изменить, удалить, порядок вверх/вниз, «Проверить название» для теста.
- **Автосохранение и обучение** — интервал автосохранения (по умолчанию 30 мин), кнопка «Сохранить сейчас», «Обучить по файлу исправлений…».
- **Подсказка** — встроенная справка.

### Размер окна и значок
Окно не бывает больше экрана. Значок окна и панели задач берётся из exe.

## 4. Как обучать правильно

### 4.1. Главный принцип
Память — единственный источник обучения. Всё, что в неё попало, алгоритм считает истиной и повторяет с уверенностью 100%. Ошибочная запись хуже, чем отсутствие записи.

### 4.2. Ежедневная работа
1. Загрузите файл и сопоставьте.
2. Просмотрите таблицу целиком или хотя бы всё, что ниже 0,85. Начните с фильтра «Низкая уверенность».
3. Каждую ошибку исправляйте двойным кликом. Исправление сразу попадает в память.
4. Для одинаковых названий используйте «Назначить эту группу всем строкам с таким же названием», для похожих подряд идущих — Ctrl+D.
5. Сохраните результат и лог.

Чего не делать:
- Не назначайте группу «на глаз» ради скорости: одна неверная запись даёт неверные подсказки для похожих названий.
- Не протягивайте Ctrl+D по непроверенным строкам: протянутые строки запоминаются.
- Не рассчитывайте на Ctrl+Z для памяти.

### 4.3. Что лучше: правило или память
- **Память** — для точных названий. Обучается сама.
- **Правило** — для широкого шаблона, который всегда ведёт в одну группу: «помпа» → «Водяной насос / Помпа». Срабатывает раньше подбора и не требует накопления примеров.
- Не делайте слишком общих правил: фраза «ремкомплект» сгребёт всё подряд. Проверяйте кнопкой «Проверить название».
- Жёсткие правила не всегда точны; используйте их только там, где группа однозначна.
- Помните: точная запись в памяти сильнее правила.

### 4.4. Обучение по логу
Сохранённый лог (`match_log.xlsx`) — главный способ дообучить программу и улучшить алгоритм. Его столбцы:

| Столбец | Что в нём |
|---|---|
| Название, Очищенное_название, Главное_слово | Исходное название, как его видит алгоритм, и главное слово |
| Предложенная_группа, Уверенность | Что предложено и с какой уверенностью |
| Топ2_…, Топ3_… | Альтернативы |
| Источник | `history` (память), `rule` (правило), `scoring` (подбор), `none` (не определено) |
| Правило | Сработавшее правило |
| Совпавшие_слова, База_IDF, Покрытие_группы, Бонус_… , Итоговый_score, Отрыв_от_второй, … | Технические детали подсчёта |
| Итоговая_группа_после_правок | Группа, которая стояла в таблице на момент сохранения лога |

Чтобы лог показал ошибки, сохраняйте его **после** ручной проверки. Тогда по расхождению «Предложенная_группа» ≠ «Итоговая_группа_после_правок» видно, где алгоритм ошибся.

**Настройки → «Обучить по файлу исправлений…»** принимает такой лог (или любой Excel со столбцами «Название» и «Группа»). Для лога программа спросит, что запомнить:
- **Да** (рекомендуется) — только строки, которые вы **исправили**. Непроверенные предложения в память не попадут.
- **Нет** — все строки, включая принятые без правок. Используйте, только если проверили каждую строку.
- **Отмена** — ничего не делать.

Если в логе нет ни одного исправления, ответ «Да» ничего не запомнит, а «Нет» запомнит все предложения как истину.

Совет: исправления, сделанные вручную в программе, уже в памяти. Повторно загружать тот же лог не нужно.

### 4.5. Если подсказки ухудшились
1. Проверьте, что `groups.txt` не изменился и не содержит повторов или латинских букв внутри русских слов (например, «Прокладкa» с латинской «a»).
2. Откройте лог и отфильтруйте строки, где `Источник` = `history` и группа неверная. Это ошибочные записи памяти: исправьте их, назначив верную группу заново.
3. Сравните точность на истории скриптом `check_matcher_loo.py`.
4. Если ошибки повторяются в одном семействе названий, пришлите лог для донастройки алгоритма (синонимы и сокращения живут в `matcher.py`).

### 4.6. Резервные копии и восстановление
- Перед крупными действиями (импорт файла исправлений) копируйте `matching_memory.json`.
- Программа сама хранит `matching_memory.json.bak` и папку `remzona_groups_logs`.
- Если память повреждена, программа покажет предупреждение, восстановит её из `.bak` и сохранит повреждённый файл рядом как `*.corrupt-…`.

### 4.7. Чек-лист
**После каждой партии:** сохранить результат и лог (после ручной проверки).

**Раз в несколько партий:** запустить `check_matcher_loo.py`, посмотреть лог на повторяющиеся ошибки.

**После смены `groups.txt`:** просто перезапустить программу, отдельного переобучения не требуется.

## 5. Справочник функций

### `matcher.py`, класс `SmartMatcher`

**Создание:** `SmartMatcher(groups, memory_file="matching_memory.json", generic_groups=None, generic_margin=None, rules=None)`

| Метод | Что делает |
|---|---|
| `find_best_group(name, return_debug=False, top_n=3)` | Главная функция. Возвращает `(группа, уверенность)`, при `return_debug=True` ещё словарь `debug` (`source`, `top`, `cleaned`, `head_word`, `score`, `gap` и др.). Группа `None`, если определить не удалось |
| `remember(name, group)` | Запоминает выбор: очищает название, кладёт в память, пересчитывает выученное, сохраняет файл |
| `save_memory()` | Атомарная запись памяти, прежняя версия остаётся в `.bak` |
| `set_rules(rules)` | Задаёт правила: список `{"pattern": str, "group": str, "regex": bool}` |
| `match_rule(cleaned)` | Ищет первое подходящее правило |
| `load_history(history)` | Заменяет историю словарём и перестраивает индексы |
| `unremember_key(key)` / `restore_key(key, group)` | Временно убрать запись и вернуть (для проверок leave-one-out) |

Атрибуты: `history` (очищенное название → группа), `learned` (слова → группы), `memory_file`, `memory_error` (текст, если файл памяти был повреждён).

**Настройка алгоритма.** Словари и регулярки (`ABBREV`, `SYNONYM_ADDITIONS`, `MODIFIERS`, `STOPWORDS`, `STEM_ENDINGS` и др.) лежат в отдельном файле `matcher_data.py`, его можно править без `matcher.py`; оба файла должны быть в одной папке. Числовые веса остаются в `matcher.py`.

**Содержимое:**
- `ABBREV` — сокращения и замены слов («стаб.» → «стабилизатор», «облицовка порога» → «накладка на порог» и т. д.);
- `SYNONYM_ADDITIONS` — слова, которые дописываются к названию, чтобы оно нашло нужную группу;
- `MODIFIERS` — слова-модификаторы (стороны, цвета, размеры), не влияющие на выбор группы;
- `STEM_ENDINGS`, `STOPWORDS` — окончания и служебные слова;
- веса подбора (`KNN_WEIGHT`, `HEAD_BONUS`, `PREC_PEN`, `HEAD_MISMATCH_PEN`, `EXACT_BONUS` и т. д.) и калибровка уверенности (`CAL_*`). Менять их без проверки на нескольких логах не стоит: текущие значения подобраны, соседние давали худший результат.

**Правила, формат:**
- Обычная фраза: очищается так же, как названия, ищется по границам слов. Пример: `тяга рулевая → Рычаги`.
- Регулярка (`"regex": true`): ищется в очищенном названии (нижний регистр, без знаков и цифр). Пример: `^помпа$ → Водяной насос / Помпа`.
- Некорректная регулярка молча пропускается: проверяйте её кнопкой «Проверить название».

### `app_config.py`
`load_config(path)` — настройки поверх значений по умолчанию. `save_config(data, path)` — сохраняет только известные ключи, возвращает `True` или `False`.

### `app.py`, класс `App` (основное)
`load_and_match` — шаг 1; `save_result`, `save_match_log` — шаги 2 и 3; `fill_tree` — таблица и фильтры; `open_topn_popup`, `open_search_popup` — выбор группы; `fill_down_selection` — протягивание; `apply_to_same_name` — группа всем одинаковым названиям; `create_rule_from_row` — правило из строки; `undo_last` — отмена; `autosave_tick` — автосохранение; `import_corrections` — обучение по файлу исправлений; `_fit_columns` — пропорциональная ширина столбцов.

## 6. Известные ограничения
- Ctrl+Z не откатывает память.
- Память сильнее правил.
- Пока в памяти мало примеров, названия редких групп угадываются хуже; помогают синонимы в `matcher.py` и ваши исправления.
- Для названий, где ваш каталог принимает нестандартное решение (например, «Обивка передней двери» → «Накладка двери», а не «Дверная карта»), программа выучит ответ только после ваших исправлений.
- Если в `groups.txt` есть латинские буквы внутри русских слов или повторы, названия в итоговом Excel могут не совпасть с каталогом. Повторы программа при загрузке убирает.
